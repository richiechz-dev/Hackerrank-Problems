Descripción
Este repositorio centraliza soluciones a problemas de HackerRank con el objetivo de documentar y demostrar progreso y habilidades en programación algorítmica y estructuras de datos. El enfoque principal es calidad de código, claridad en las soluciones y trazabilidad de la evolución técnica sin ayuda externa como la IA, solo investigación prueba error.

Estructura del Repositorio 📁
La organización sigue una convención consistente para facilitar la navegación y la búsqueda de soluciones:
  - Lenguaje: Python, Java, SQL, etc.
  - Dominio: Algorithms, Data-Structures, Implementation, OOP, etc.
  - NombreDelProblema: nombre descriptivo del ejercicio (camel_case o snake_case según el lenguaje).

Ejemplo (presente en el repositorio):
- Hackerrank-Problems/Algorithms/Warmup/05_Diagonal_Difference.py
- Hackerrank-Problems/Algorithms/Warmup/06_PlusMinus.py
- Hackerrank-Problems/Algorithms/Warmup/07_Staircase.py
- Hackerrank-Problems/Algorithms/Warmup/08_Min_Max.py
- Hackerrank-Problems/Algorithms/Warmup/09_Birthday_Cake_Candles.py

Cómo ejecutar los ejercicios (rápido) ▶️
- Requisitos: Python 3.x instalado.
- Ejecutar un script individual:
  - Abrir terminal en la raíz del repositorio.
  - Ejemplo: python Hackerrank-Problems/Algorithms/Warmup/05_Diagonal_Difference.py
- Contribuciones futuras: añadiré scripts de prueba (unit tests) y utilidades para ejecutar suites completas.

Buenas prácticas y convenciones ✅
- Nombres de archivos descriptivos que reflejan el problema y/o el número asignado por HackerRank.
- Código con funciones reutilizables (cuando aplica) y bloques protectores if __name__ == "__main__".
- Comentarios en código para explicar lógica no trivial y decisiones algorítmicas.
- Formato legible siguiendo PEP 8 en Python (espacios, nombres y longitud de líneas razonable).
